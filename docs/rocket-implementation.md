# Rocket implementation

Rocket provides the next JoomEngine Playground interface and deployment workflow.

- [x] Slim, scrolling header, full-width Joomla view, rocket launch scene and branded footer.
- [x] Deploy terminology and configuration throughout, without legacy compatibility.
- [x] Visual deployment editor, complete share links, templates and component menu home pages.
- [x] Adjustable, validated PHP settings shared by browser and build runtimes.
- [x] Prepared JCB by default on PHP 8.4, with a cancellable ten-second countdown; PHP 8.5 remains selectable and MCP remains optional on Joomla 6.
- [x] Afrikaans-first multilingual deployments with all requested languages; ordinary deployments default to English.
- [x] Independently translated Rocket interface, starting in English, including RTL support.
- [x] Clear persistence, credentials, downloads and a shared header/footer hide mode with edge restore tabs that preserve the live Joomla instance.
- [x] Independent database sessions, bounded large-value exports, configuration recovery and real compiler validation.

The footer credits Vast Development Method and the JoomEngine Community. Each sentence of the smaller Joomla affiliation notice begins on a separate line. The information dialog ends with the JCB notice and the Playground Apache 2.0 license. Upstream credits remain in README and the interface information dialog.

Validation must fail early, cache reproducible build inputs and select tests according to changed behavior. A complete supported runtime matrix remains available for runtime changes and release validation without delaying ordinary UI feedback.

Runtime validation includes real PHP 8.3, 8.4 and 8.5 extension checks, 128 MiB upload handling, Joomla 5 and 6 multilingual provisioning, package installation, native configuration saves, and portable restoration. Browser checks cover data retention, PHP restarts, unchanged runtime and iframe state while hiding controls, responsive layout and independent interface languages. The pull request checks report validation for the current commit.
