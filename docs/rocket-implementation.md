This branch develops the next JoomEngine Playground release.

- [ ] Slim, scrolling header, full-width Joomla view, rocket launch scene and branded footer.
- [ ] Deploy terminology and configuration throughout, without legacy compatibility.
- [ ] Visual deployment editor, complete share links, templates and component menu home pages.
- [ ] Adjustable, validated PHP settings shared by browser and build runtimes.

- [ ] Verified bridge 0.1.3 assets, compatibility fixes and focused validation.
